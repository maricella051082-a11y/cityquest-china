# CityQuest China 城市奇遇

Starter for `@CityQuestChinaBot`.

## Local run

1. Install Python 3.11+.
2. Create `.env` from `.env.example`.
3. Put the BotFather token into `.env`.
4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Run:

```bash
python main.py
```

## BotHost

Upload/push the repository to GitHub, create a Python Telegram bot on BotHost, use `main.py` as the entrypoint, and keep the token in BotHost settings/environment rather than GitHub.
